# WiFi 对时 + 设置页 + 低功耗

日期：2026-11-01
状态：已实现（feature/settings-wifi-lowpower 分支）

## 功能概述

1. **时钟页上滑打开设置页**（250ms 滑动动画），设置页下滑返回；WiFi 页从设置页进入。
2. **时钟页顶部状态栏已移除**（时间/电量/图标），时钟页面只保留日期+时间点阵。
3. **WiFi 对时**：设置页 → WiFi → 自动扫描 → 选择网络：
   - 开放网络直连；有保存密码直连；否则弹出 T9 九宫格键盘输入
   - 连接 → SNTP（aliyun/pool.ntp.org/time.google.com，TZ=CST-8）→ 写 PCF85063 → 回读校验
   - **无论成败立即断开并 deinit**（释放约 50KB 堆），WiFi 只在对时瞬间存在
4. **低功耗**：60 秒无触摸 → 亮度降至 4%（`BSP_LCD_BRIGHTNESS_LOW_PCT`，待真机标定）；触摸唤醒只恢复亮度，首次触摸吞掉防误触；时钟每秒走时不停；**绝不自动开启 WiFi/蓝牙**。
5. **T9 九宫格键盘**：多击循环含数字（按 2 出 `a→b→c→2`）、800ms 提交、⇧ 粘性大小写、`#+=`/`abc` 符号页切换、⌫ 退格（长按清空）、64 字符上限。

## 交互细节

- 亮度滑条 10-100%，实时生效，NVS `settings/brightness` 持久化，重启保持
- 电量行每 5s 刷新（AXP2101 寄存器 0xA4）
- WiFi 凭据存 NVS `wifi` 命名空间（`cred0`..`cred7`），按 SSID 去重，满 8 条淘汰最旧；连接成功才保存；保存的密码认证失败自动删除并重新要求输入
- 中文 SSID 列表显示为方块（无中文字库，省 ~500KB flash），选择与连接按字节透传不受影响
