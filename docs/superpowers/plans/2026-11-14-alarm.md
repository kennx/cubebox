# 闹钟功能 实施计划

> **For agentic workers:** 本计划在执行中同步撰写（用户授权 Agent 全权决断）；
> spec 见 `docs/superpowers/specs/2026-11-14-alarm-design.md`（决策记录以 spec 为准）。

**Goal:** 网页配置闹钟（模式/时间/星期），到点响铃 3 分钟（合成哔哔声、30s 渐入、最大音量），KEY 停止；响铃屏 + console `ALARM` 强制响铃验证途径。

**Architecture:** `alarm.c`（纯逻辑调度）+ `config_model/store`（alarm_* 字段/NVS）→ main.c 胶水（响铃状态机）→ `hal_audio`（esp_codec_dev+ES8311 懒建懒拆）+ `app_alarm`（瞬态响铃屏）→ web AlarmCard（proto 4）。

## Review Focus（自查要点）

- 分钟去重键用 epoch 分钟号（`now_s/60`）：跨天/跨年唯一，同分钟轮询不重复触发。
- 单次模式**触发即刻**持久化关闭（先落盘再响）——响铃中重启不会次日重复响。
- `alarm_service` 持续注入活动：3 分钟响铃不被低功耗降亮度。
- hal_audio 建链/拆链都在播放任务单一上下文；gui_task 仅 start/stop 置位等待。
- web `alarm_*` 字段 optional（旧固件 proto<4 不回传，卡片门控展示"固件不支持"）。

## 执行中发现并修复

1. **`i2s_channel_enable` 重复调用**：esp_codec_dev 的 open 内部已 enable I2S 通道
   （`platform/audio_codec_data_i2s.c`），外部再调返回 `INVALID_STATE` 被误判为建链
   失败——首版真机日志 `audio chain build failed` 定位（分步 stage 日志 + I2C probe
   @0x18 present），删除冗余 enable 后链路正常。教训：esp_codec_dev 全托管 I2S 通道
   生命周期，外部只负责 `i2s_new_channel` + `init_std_mode`。
2. **响铃屏截图解码**：SNAP 流出的是显示旋转后的帧缓冲，设备横放时需按 CCW 旋转
   解码点阵；时间带/ALARM 亮灭相位/KEY 带与字体表确定性比对全部 100% 匹配。
