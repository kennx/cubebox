# 经典双行全数字与英文点阵时钟集成设计规范

本规范详细说明了在 ESP32-C6-Touch-AMOLED-2.16 设备上，如何实现纯手写点阵的双行时钟表盘：第一行为 8x8 大圆点时间（HH:MM:SS），第二行为 4x4 圆点紧凑英文日期（MM-DD WWW），完全不依赖 LVGL 的矢量 Label 组件，呈现纯粹的极简硬核点阵视觉特征。

---

## 1. 扩充点阵字模库与索引映射

为了在第二行渲染英文日期（如 `"06-01 MON"`），我们必须对原本仅有 11 个字符的 `font_5x7` 库进行扩展。

### 1.1 字模扩充字形定义
我们在 `main.c` 头部将 `font_5x7` 库扩展至 26 个字符，手写定义大写英文字母与减号、空格的经典 5x7 字形：
```c
static const uint8_t font_5x7[26][7] = {
    {0x0E, 0x11, 0x11, 0x11, 0x11, 0x11, 0x0E}, // 0: 00-09 数字

    {0x0E, 0x11, 0x01, 0x02, 0x04, 0x08, 0x1F}, // 2
    {0x1F, 0x01, 0x02, 0x0E, 0x01, 0x11, 0x0E}, // 3
    {0x02, 0x06, 0x0A, 0x12, 0x1F, 0x02, 0x02}, // 4
    {0x1F, 0x10, 0x1E, 0x01, 0x01, 0x11, 0x0E}, // 5
    {0x0E, 0x11, 0x10, 0x1E, 0x11, 0x11, 0x0E}, // 6
    {0x1F, 0x01, 0x02, 0x04, 0x08, 0x08, 0x08}, // 7
    {0x0E, 0x11, 0x11, 0x0E, 0x11, 0x11, 0x0E}, // 8
```

### 1.2 字符到点阵库索引映射函数
为了在绘制循环中能够顺畅地查找对应字模，实现字符映射转换逻辑：
```c
static int char_to_font_idx(char ch)
{
    if (ch >= '0' && ch <= '9') return ch - '0';
    if (ch == ':') return 10;
    if (ch == '-') return 11;
    if (ch == ' ') return 12;
    if (ch >= 'a' && ch <= 'z') ch = ch - 'a' + 'A'; // 小写转大写
    switch (ch) {
        case 'A': return 13;
        case 'D': return 14;
        case 'E': return 15;
        case 'F': return 16;
        case 'I': return 17;
        case 'M': return 18;
        case 'N': return 19;
        case 'O': return 20;
        case 'R': return 21;
        case 'S': return 22;
        case 'T': return 23;
        case 'U': return 24;
        case 'W': return 25;
        default:  return 12; // 默认空格
    }
}
```

## 2. 双行空间几何与绝对定位设计

我们在 480x480 圆屏正中央，通过像素级偏移划分两块互不干扰的渲染目标框：

### 2.1 第一行：点阵时间大字 (HH:MM:SS)
*   **字元内容**：来自全局字符串 `current_time_str`（如 `"18:45:30"`，共 8 个字符）。
*   **尺寸参数**：网格 `9x9` 像素。圆点 `8x8` 像素，网格纯黑间距 `1` 像素。
*   **整体尺寸**：共 47 网格列，7 网格行。物理总宽度 423 像素，物理总高度 63 像素。
*   **绝对偏移**：
    *   `TIME_OFFSET_X = 28`（左边距 28px，右边距 29px，实现精细水平对称）。
    *   `TIME_OFFSET_Y = 170`（物理 Y 轴渲染范围为 `[170, 233]` 像素）。

### 2.2 第二行：点阵日期小字 (MM-DD WWW)
*   **字元内容**：来自全局字符串 `current_date_str`（如 `"06-01 MON"`，共 10 个字符）。
*   **尺寸参数**：网格 `6x6` 像素。圆点 **`4x4`** 像素，网格纯黑间距 **`2`** 像素（即网格中 $lx < 4$ 且 $ly < 4$ 时发光，剩余 2 像素为黑色边缝）。这能保证点阵小字极为清爽、透气。
*   **整体尺寸**：共 59 网格列，7 网格行。物理总宽度 354 像素，物理总高度 42 像素。
*   **绝对偏移**：
    *   `DATE_OFFSET_X = 63`（左边距 63px，右边距 63px，实现完美水平对称）。
    *   `DATE_OFFSET_Y = 258`（物理 Y 轴渲染范围为 `[258, 299]` 像素）。

## 3. 双行像素映射渲染逻辑

我们在 `lvgl_flush_cb` 冲刷回调函数中实时进行这二个绝对目标框的拦截与格点映射判定：

对于屏幕上的任意一个全局物理坐标 `(global_x, global_y)`：
1.  **第一行时间区域判定**：
    计算相对时间起始点的坐标：`tx = global_x - 28`, `ty = global_y - 170`。
    若 $tx \in [0, 422]$ 且 $ty \in [0, 62]$：
    *   网格索引：`grid_x = tx / 9`, `grid_y = ty / 9`。
    *   网格内坐标：`lx = tx % 9`, `ly = ty % 9`。
    *   若 $lx < 8$ 且 $ly < 8$：
        *   字符位判定：`char_idx = grid_x / 6`, `char_col = grid_x % 6`。
        *   若 `char_col < 5`，根据字符字模亮灭涂发光淡灰 (`#E5E5E5`) 或灭灯纯黑 (`#000000`)；若 `char_col == 5` 涂纯黑。
    *   若 $lx == 8$ 或 $ly == 8$，涂 `color_map[i]` 保持背景纯黑。
2.  **第二行日期区域判定**：
    计算相对日期起始点的坐标：`dx = global_x - 63`, `dy = global_y - 258`。
    若 $dx \in [0, 353]$ 且 $dy \in [0, 41]$：
    *   网格索引：`grid_x = dx / 6`, `grid_y = dy / 6`。
    *   网格内坐标：`lx = dx % 6`, `ly = dy % 6`。
    *   若 $lx < 4$ 且 $ly < 4$：
        *   字符位判定：`char_idx = grid_x / 6`, `char_col = grid_x % 6`。
        *   若 `char_col < 5`，提取 `current_date_str[char_idx]` 转换为字元索引，查询 `font_5x7` 状态。点亮涂淡灰 (`#E5E5E5`)，未点亮涂纯黑 (`#000000`)；若 `char_col == 5` 涂纯黑。
    *   若 $lx \ge 4$ 或 $ly \ge 4$，涂 `color_map[i]` 保持背景纯黑。
3.  **其他非介入区域**：
    *   透传 `color_map[i]` 的原始像素值。

## 4. 验证与测试规程

1.  **静态编译校验**：确保新增的大写英文字形字模数组、`char_to_font_idx` 函数以及 `lvgl_flush_cb` 中的分行判定逻辑能百分之百编译通过，无警告。
2.  **绝对对称性与美感校验**：烧录后观察 AMOLED 屏，确认：
    *   第一行大字时间和第二行小字日期左右两侧完全水平居中，无任何左/右偏斜。
    *   第二行小字日期 `"MM-DD WWW"` 显示清晰可辨，圆点无光晕粘连。
    *   第一行与第二行之间有 25px 的呼吸感透气间距，两行总分布在圆形屏幕正中央，和谐美观。
