# 优雅点阵时钟与现代矢量英文日期集成设计规范

本规范详细说明了在 ESP32-C6-Touch-AMOLED-2.16 设备上，如何实现 8x8 圆点大点阵时间与 Montserrat-22 矢量英文日期标签的优雅融合。

---

## 1. 界面空间几何设计

为确保界面富有空间美感、合理的呼吸感及信息层级对比，我们做以下的空间几何坐标划分。
*   **屏幕总尺寸**：480x480 像素，圆心在 `(240, 240)`。
*   **点阵时间 (HH:MM:SS)**：
    *   总网格大小：9x9 像素。圆点 8x8 像素，间距 1 像素。
    *   总物理宽度：423 像素。总物理高度：63 像素。
    *   X 轴渲染范围：`[28, 450]` 像素（左边距 28px，右边距 29px）。
    *   Y 轴渲染范围：`[208, 271]` 像素（上下边距各 208px）。
*   **矢量英文日期 (Mon Jun 01 2026)**：
    *   字体类型：LVGL 内置 Montserrat-22 字体。
    *   文字颜色：高对比度淡灰色 (`#E5E5E5`)，与时间圆点颜色一致。
    *   空间对齐：居中对齐，纵向相对于圆心向上偏移 `-60` 像素。
    *   Y 轴物理渲染范围：约 `[169, 191]` 像素。
    *   与下方时间点阵上边缘的物理间距为 **17** 像素，视觉比例非常匀称。

---

## 2. 软件渲染突破：点阵与矢量融合架构

为了解决手写点阵在 `lvgl_flush_cb` 冲刷时强制将时钟区域外全屏涂黑，导致 LVGL 矢量日期标签无法显示的问题，我们将冲刷机制进行通道重构：
1.  **相对坐标偏移映射**：
    $$\text{local\_x} = \text{global\_x} - 28$$
    $$\text{local\_y} = \text{global\_y} - 208$$
2.  **区域内点阵强制介入**：
    若 $\text{local\_x} \in [0, 422]$ 且 $\text{local\_y} \in [0, 62]$：
    *   判定为时钟大字框。根据 `grid_x` 和 `grid_y` 计算点阵亮灭状态。
    *   若是发光圆点发光位（$lx < 8$ 且 $ly < 8$），根据字模点亮状态涂发光淡灰 (`#E5E5E5`) 或灭灯纯黑 (`#000000`)。
    *   若是 1px 细线纯黑间距位（$lx == 8$ 或 $ly == 8$）或字符间 1 网格间隔列（$char\_col == 5$），我们**不再强行涂纯黑，而是透传 `color_map[i]` 的像素颜色**，保持背景纯黑。
3.  **区域外像素通道透传**：
    若坐标不在时钟大字框内，**一律完整透传原始 `color_map[i]` 颜色数据**。
4.  **架构优势**：
    该透传架构使 LVGL 能够如常在点阵时钟外渲染任何矢量组件（如 `date_label`），完全避免了像素重绘冲突，奠定了设备多挂件（Widgets）共存的基础。

## 3. RTC 驱动功能升级：完整日期时间读取

我们扩展主程序对 AXP2101 后备电池供电的 PCF85063 RTC 芯片的 I2C 通信。

### 3.1 一次性突发读取 (Burst Read)
从 PCF85063 的 Seconds 寄存器 `0x04` 开始，连续读取 7 个字节的寄存器数据。
```c
esp_err_t rtc_pcf85063_get_datetime(uint8_t *hour, uint8_t *minute, uint8_t *second,
                                     uint8_t *day, uint8_t *weekday, uint8_t *month, uint8_t *year);
```
读取对应寄存器解析定义：
*   字节 0 (`0x04`)：秒（Seconds, BCD 码, 低 7 位有效）
*   字节 1 (`0x05`)：分（Minutes, BCD 码, 低 7 位有效）
*   字节 2 (`0x06`)：时（Hours, BCD 码, 低 6 位有效）
*   字节 3 (`0x07`)：日（Days, BCD 码, 低 6 位有效）
*   字节 4 (`0x08`)：星期（Weekdays, BCD 码, 低 3 位有效，`0` 代表星期日，`1` 代表星期一，以此类推）
*   字节 5 (`0x09`)：月（Months, BCD 码, 低 5 位有效）
*   字节 6 (`0x0a`)：年（Years, BCD 码, 范围 00-99，对应 2000-2099 年）

### 3.2 越界安全防护
为了防止 RTC 芯片在首次启动、电量耗尽或未校准时，读出非法的月份（如 0）或星期（如 7）导致数组越界崩溃，我们在格式化时进行安全兜底判定：
*   若 `weekday > 6`：强制设定 `weekday = 1`（星期一）。
*   若 `month < 1 || month > 12`：强制设定 `month = 6`（六月）。
*   若 `day < 1 || day > 31`：强制设定 `day = 1`（1号）。
*   若 `year > 99`：强制设定 `year = 26`（2026年）。

## 4. 验证与调试流程

1.  **静态编译校验**：修改 `main.c` 的 RTC 函数和 LVGL 控件创建逻辑，确保无编译错误和警告。
2.  **绝对坐标与重合校验**：在屏幕上观察，确认日期白色文字无模糊、缺失、偏斜，时钟 8x8 圆点大字均匀整齐，证明像素通道透传架构绝对工作正常。
3.  **时钟日期精度与同步校验**：观察时间跳秒与日期的静态稳定性。
