# Nothing Phone 风格水平全数字点阵时钟设计规范

本规范详细说明了基于 ESP32-C6-Touch-AMOLED-2.16 开发板和 LVGL 图形库实现 Nothing Phone 风格水平点阵时钟的设计方案。该时钟将在 480x480 圆形屏幕上，充分利用空间并遵循干脆跳秒、无复杂过渡动画的极简美学。

---

## 1. 核心视觉设计与空间计算

### 1.1 像素字模与网格定义
我们不依赖外部图片或自定义字体，而是通过纯 C 语言定义的点阵字模，使用 LVGL 动态控制圆形发光像素点。
- **字模尺寸**：每个字符采用 `5x7` 点阵。
- **支持字符**：`0-9` 及冒号 `:`，共 11 个字符。
- **网格数据结构**：每个字符由一个 byte 数组表示，最高 5 位（从左到右）有效：
  ```c
  static const uint8_t font_5x7[11][7] = {
      {0x0E, 0x11, 0x11, 0x11, 0x11, 0x11, 0x0E}, // 0
      {0x04, 0x0C, 0x04, 0x04, 0x04, 0x04, 0x0E}, // 1
      {0x0E, 0x11, 0x01, 0x02, 0x04, 0x08, 0x1F}, // 2
      {0x1F, 0x01, 0x02, 0x0E, 0x01, 0x11, 0x0E}, // 3
      {0x02, 0x06, 0x0A, 0x12, 0x1F, 0x02, 0x02}, // 4
      {0x1F, 0x10, 0x1E, 0x01, 0x01, 0x11, 0x0E}, // 5
      {0x0E, 0x11, 0x10, 0x1E, 0x11, 0x11, 0x0E}, // 6
      {0x1F, 0x01, 0x02, 0x04, 0x08, 0x08, 0x08}, // 7
      {0x0E, 0x11, 0x11, 0x0E, 0x11, 0x11, 0x0E}, // 8
      {0x0E, 0x11, 0x11, 0x0F, 0x01, 0x11, 0x0E}, // 9
      {0x00, 0x04, 0x00, 0x00, 0x00, 0x04, 0x00}  // : (冒号只亮第2和第6行的中间点)
  };
  ```

### 1.2 中央时间点阵尺寸计算
- **屏幕大小**：480 x 480 像素，圆心在 `(240, 240)`。
- **点阵圆点大小 (`DOT_SIZE`)**：`6` 像素。
- **点阵圆点间距 (`DOT_GAP`)**：`2` 像素。
- **单个字符大小**：
  - 宽度 = `5 * DOT_SIZE + 4 * DOT_GAP = 5 * 6 + 4 * 2 = 38` 像素。
  - 高度 = `7 * DOT_SIZE + 6 * DOT_GAP = 7 * 6 + 6 * 2 = 54` 像素。
- **字符间距 (`CHAR_GAP`)**：`10` 像素。
- **时钟总长度 (8个字符: HH:MM:SS)**：
  - 总宽度 = `8 * 38 + 7 * CHAR_GAP = 304 + 70 = 374` 像素。
  - 在 480 宽度的屏幕中，左右对称居中，起始 X 坐标 = `(480 - 374) / 2 = 53` 像素。
  - 起始 Y 坐标 = `(480 - 54) / 2 = 213` 像素。
  此尺寸计算保证了所有点阵在 480 像素的圆形屏幕中完全居中，且完全处于圆形边界内的安全区域。

### 1.3 边缘矩阵圆环设计
为了填充水平时钟上下的空旷区域，同时强调圆形屏幕的几何美感：
- **圆环半径 (`RING_RADIUS`)**：`225` 像素。
- **点阵数量**：`60` 个点（对应 60 秒的极坐标分布）。
- **坐标计算**：
  对每一个 $i \in [0, 59]$，其在极坐标下的角度为 $\theta = i \times 6^\circ - 90^\circ$（以正上方为 0 秒起算点）：
  $$x = 240 + 225 \times \cos(\theta)$$
  $$y = 240 + 225 \times \sin(\theta)$$
- **视觉逻辑**：
  - 常规点阵大小为 `4` 像素，呈微弱暗白色（或极深灰色，如 `0x333333`）。
  - 当前秒数对应位置的圆点变为亮红色（`0xFF0000`），大小增加为 `6` 像素，代表秒针。
  - 随着时间流逝，秒针红点干脆地在 60 个位置间跳动更新，无呼吸渐变效果。

## 2. 软件架构设计

### 2.1 LVGL 对象树结构
为保证嵌入式性能和低内存消耗，全部使用 LVGL 基础对象 `lv_obj` 来构建。
- `scr` (主屏幕背景，纯黑)
  - `ring_dots[60]` (外围 60 个秒针指示圆点，圆形样式)
  - `time_container` (包裹整个水平时间组件的容器，透明)
    - `char_containers[8]` (代表 HH:MM:SS 的 8 个字符容器)
      - `dot_objs[35]` (每个字符内部由 35 个微小 `lv_obj` 组成的 5x7 圆网格)

### 2.2 核心渲染与状态更新逻辑
- **字模状态机**：
  更新每一位字符时，将 `hour`, `minute`, `second` 格式化为字符数组，如 `['1', '2', ':', '3', '4', ':', '5', '6']`。
  根据字符的值找到 `font_5x7` 对应的字模行数据，然后循环 `5x7` 像素：
  - 如果字模数据中该位为 `1`：设置该像素 `lv_obj` 的背景色为高亮冷白（如 `0xFFFFFF`）。
  - 如果该位为 `0`：设置该像素 `lv_obj` 的背景色为暗黑色（如 `0x1A1A1A`）。
- **更新速率**：
  为了响应“正常的时间变化”，整个界面采用 **每秒（1000ms）更新一次** 的定时器。
  在 `gui_task` 轮询循环中，当 PCF85063 读回的时分秒数据发生变化时，瞬间刷新 8 个字符中受影响像素的亮暗状态，同时更新秒环的红色亮格。
  此种更新方式完全移除了任何 LVGL 动画和透明度过渡，保证时间更新干净利落、零卡顿。

## 4. 验证与调试规程

1. **静态编译检查**：确保新引入的 5x7 字模数组以及 LVGL 批量创建对象的循环无内存泄漏。
2. **字符对称性验证**：在屏幕上渲染 `88:88:88`，确认 374 像素总宽在 480 像素屏幕中对称且完整居中，左右没有偏斜。
3. **跳秒同步测试**：观察秒环红色高亮点与中心 `SS` 数字的最后一位，确保跳变时机完全同步，无延迟或提前。
4. **性能监视**：检查 CPU 占用，确认由于移除了呼吸动画，每秒更新时无额外开销，保持低功耗运行。
