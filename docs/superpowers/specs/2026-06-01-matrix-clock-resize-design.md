# Nothing Phone 风格水平点阵时钟尺寸与居中优化设计规范

本规范详细说明了基于 ESP32-C6-Touch-AMOLED-2.16 设备，对水平点阵时钟进行尺寸放大（由 6x6 圆点改大为 8x8 圆点）以及像素级绝对居中对齐的重构方案。

---

## 1. 核心视觉与空间尺寸重构

由于设备采用 480x480 分辨率的圆形 AMOLED 屏幕，为了兼顾“大尺寸圆点带来的饱满视觉效果”以及“左右对称的舒服边距”，我们对网格和渲染参数做如下重新定义。

### 1.1 尺寸与间距定义
*   **网格大小 (`GRID_SIZE`)**：`9` 像素（原本为 `8` 像素）。
*   **圆点尺寸 (`DOT_SIZE`)**：`8x8` 像素（原本为 `6x6` 像素，面积增大了约 **77.7%**，视觉上极为显眼和饱满）。
*   **网格间距 (`DOT_GAP`)**：`1` 像素（即圆点与圆点之间留有 1px 宽度的纯黑隔离缝隙，保持网格化特征）。

### 1.2 像素级绝对居中计算
为了摆脱原网格强行与屏幕左上角 $(0,0)$ 对齐导致的时钟左偏斜问题，我们引入物理像素级的起始偏移量（`OFFSET_X` 和 `OFFSET_Y`）。
*   **时钟总宽度**：
    *   HH:MM:SS 共 8 个字符。
    *   前 7 个字符加间隔：$7 \times (5 + 1) = 42$ 网格。
    *   最后一个字符：$5$ 网格。
    *   总网格列数 = $42 + 5 = 47$ 网格。
    *   物理总宽度 = $47 \times 9 = 423$ 像素。
*   **时钟总高度**：
    *   采用 5x7 点阵字模。
    *   总网格行数 = $7$ 网格。
    *   物理总高度 = $7 \times 9 = 63$ 像素。
*   **完美对称偏移量**：
    *   `OFFSET_X` = $(480 - 423) / 2 = 28$ 像素。
        *   时钟在 X 轴上的像素渲染范围是 `[28, 450]` 像素。
        *   **左边距 28 像素，右边距 29 像素**，实现几乎绝对的对称与极其舒适的呼吸感边距。
    *   `OFFSET_Y` = $(480 - 63) / 2 = 208$ 像素。
        *   时钟在 Y 轴上的像素渲染范围是 `[208, 270]` 像素。
        *   **上下边距均为 208 像素**，实现正中心对齐。

## 2. 软件渲染逻辑设计

所有的重构逻辑全部在 `main/main.c` 内部的 `lvgl_flush_cb` 冲刷回调函数中实现。由于采用强制全屏重绘，此处的坐标映射能实现极高的性能与零内存开销。

### 2.1 局部坐标映射公式
对于屏幕上的任意一个全局物理坐标 `(global_x, global_y)`：
1. 计算相对时钟区域的局部坐标：
   $$\text{local\_x} = \text{global\_x} - 28$$
   $$\text{local\_y} = \text{global\_y} - 208$$
2. 若 $\text{local\_x} \in [0, 422]$ 且 $\text{local\_y} \in [0, 62]$：
   *   所属网格坐标：`grid_x = local_x / 9`，`grid_y = local_y / 9`。
   *   网格内相对坐标：`lx = local_x % 9`，`ly = local_y % 9`。
3. 若 $lx < 8$ 且 $ly < 8$：
   *   该像素属于发光圆点内部。根据点阵字模 `font_5x7` 判断是否点亮：
       *   时间字符串字符索引：`char_idx = grid_x / 6`。
       *   字符内点阵列索引：`char_col = grid_x % 6`。
       *   当 `char_col < 5` 时，获取当前字符的点亮状态：
           $$\text{is\_lit} = \frac{\text{font\_5x7}[\text{font\_idx}][\text{grid\_y}]}{2^{4 - \text{char\_col}}} \ \& \ 1$$
       *   若点亮，涂发光灰白色 (`#E5E5E5`)；若未点亮，涂灭灯深黑色 (`#000000`)。
       *   当 `char_col == 5` 时（字符间 1 网格间隔），涂纯黑色。
4. 若 $lx == 8$ 或 $ly == 8$：
   *   该像素属于网格间 1px 细线纯黑间隔，涂纯黑色。
5. 若物理坐标超出时钟局限区，涂纯黑色。

## 3. 极简调色板 (Color Palette)

| 元素 | 颜色值 | RGB 描述 | 用途说明 |
| :--- | :--- | :--- | :--- |
| **背景与间隔** | `#000000` | 纯黑 | 营造极致对比度背景，以及 1px 的网格细线间距 |
| **点阵高亮** | `#E5E5E5` | 极浅冷灰 | 发光点阵字符（高对比度发光） |
| **点阵暗色** | `#000000` | 纯黑 | 未发光圆点的底色，实现全息无缝对比度 |

## 4. 验证与调试要求

1. **静态编译检查**：在 `main.c` 中修改相关宏及 `lvgl_flush_cb` 内的数学公式，确保无编译错误和警告。
2. **像素对称性验证**：编译烧录后，确认时钟字样没有被圆形屏幕切边，且左右两侧边距视觉上完全等宽（28px/29px）。
3. **点阵饱满度验证**：观察圆点的饱满程度。8x8 的圆点相比原本的 6x6 圆点应有非常显着的视觉提升，并且 1px 的黑色间隔应当能够清晰分隔开每一个相邻点。
