# 经典两端齐平双行纯点阵时钟与英文日期设计规范

本规范详细说明了在 ESP32-C6-Touch-AMOLED-2.16 设备上，如何实现纯手写点阵的双行完美齐平表盘：第一行为 4x4 圆点英文日期（MON JUN 01 2026），第二行为 8x8 圆点大字时间（HH:MM:SS），完全不依赖 LVGL 矢量 Label，实现两端物理像素齐平，呈现Nothing Phone标志性的几何对称美学。

---

### 1.2 高性能字符映射
```c
static int char_to_font_idx(char ch)
{
    if (ch >= '0' && ch <= '9') return ch - '0';
    if (ch == ':') return 10;
    if (ch == '-') return 11;
    if (ch == ' ') return 12;
    if (ch >= 'a' && ch <= 'z') ch = ch - 'a' + 'A';
    if (ch >= 'A' && ch <= 'Z') return 13 + (ch - 'A');
    return 12; // 默认空格
}
```

## 2. 完美的双行「两端对齐」空间设计

第一行日期（15个字符）与第二行时间（8个字符）通过像素级调谐，实现 423 像素宽度的绝对齐平：

### 2.1 第一行：点阵日期小字 (MON JUN 01 2026) —— 在上方
*   **字元内容**：全局 `current_date_str`（格式 `"WWW MMM DD YYYY"`，如 `"MON JUN 01 2026"`，共 15 字符）。
*   **网格尺寸**：网格 `5x5` 像素。圆点 `4x4` 像素，间距 `1` 像素。
*   **绝对偏移**：
    *   `DATE_OFFSET_X = 28`（左边距 28px，右边距 29px，与时间框完全对齐）。
    *   `DATE_OFFSET_Y = 170`（物理 Y 轴渲染范围为 `[170, 204]` 像素，高度为 35px）。
*   **两端对齐像素查表法**：
    为了使 15 个字符（每个字身宽 25px）物理上无缝填满 423px 的框：
    ```c
    static const int date_char_x[15] = {
        0, 29, 57, 85, 114, 142, 170, 199, 227, 255, 284, 312, 340, 369, 398
    };
    ```
    每一项为字符在 423 像素局部区域内的起始 X 物理像素坐标，第 14 个字符的右边缘恰好落在 `398 + 25 = 423` 像素，实现神仙级两端绝对齐平。

### 2.2 第二行：点阵时间大字 (HH:MM:SS) —— 在下方
*   **字元内容**：全局 `current_time_str`（格式 `"HH:MM:SS"`，共 8 字符）。
*   **网格尺寸**：网格 `9x9` 像素。圆点 `8x8` 像素，间距 `1` 像素。
*   **物理宽度**：共 47 网格列，7 网格行。物理总宽度 423 像素，物理总高度 63 像素。
*   **绝对偏移**：
    *   `TIME_OFFSET_X = 28`（左边距 28px，右边距 29px）。
    *   `TIME_OFFSET_Y = 229`（物理 Y 轴渲染范围为 `[229, 292]` 像素）。

## 3. 双行像素渲染映射公式

我们在 `lvgl_flush_cb` 冲刷回调函数中实时判定物理像素 `(global_x, global_y)`：

1.  **第一行日期介入判定**：
    计算相对起始点的坐标：`dx = global_x - 28`, `dy = global_y - 170`。
    若 $dx \in [0, 422]$ 且 $dy \in [0, 34]$：
    *   网格内坐标：`lx = dx % 5`, `ly = dy % 5`。
    *   若 $lx < 4$ 且 $ly < 4$：
        *   定位字符索引 `char_idx`：循环 15 个字符，判定 `dx >= date_char_x[c] && dx < date_char_x[c] + 25`。
        *   若找到有效 `char_idx`：
            *   计算字符内点阵列索引：`char_col = (dx - date_char_x[char_idx]) / 5`。
            *   若 `char_col < 5`，获取字符 `ch = current_date_str[char_idx]`。根据 `char_to_font_idx(ch)` 查 `font_5x7[font_idx][dy / 5]` 得到亮灭状态。
        *   若点亮涂淡灰 (`#E5E5E5`)，未点亮涂纯黑 (`#000000`)。
    *   若 $lx == 4$ 或 $ly == 4$，透传 `color_map[i]`。
2.  **第二行时间介入判定**：
    计算相对起始点的坐标：`tx = global_x - 28`, `ty = global_y - 229`。
    若 $tx \in [0, 422]$ 且 $ty \in [0, 62]$：
    *   网格索引：`grid_x = tx / 9`, `grid_y = ty / 9`。
    *   网格内坐标：`lx = tx % 9`, `ly = ty % 9`。
    *   若 $lx < 8$ 且 $ly < 8$：
        *   字符位判定：`char_idx = grid_x / 6`, `char_col = grid_x % 6`。
        *   若 `char_col < 5`，根据字符字模亮灭涂发光淡灰 (`#E5E5E5`) 或灭灯纯黑 (`#000000`)；若 `char_col == 5` 涂纯黑。
    *   若 $lx == 8$ 或 $ly == 8$，透传 `color_map[i]`。
3.  **其他非时钟区域**：
    *   透传 `color_map[i]` 的原始像素值。
